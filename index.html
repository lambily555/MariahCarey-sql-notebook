W3 主线还要学什么

当前：EXISTS（是否存在）、ANY（至少一个满足）和 ALL（全部满足）。接下来完成 CASE、Null Functions，并补学 SQL Dates。

达到面试水平还要补什么

日期与字符串处理、子查询、CTE（给复杂查询起临时名字）、窗口函数（排名、累计、环比）、每组 Top N、去重、留存，以及先判断“每一行代表什么”的数据粒度意识。

转入 Python 前的检查线：W3 主线学到 Null Functions，并完成 SQL Dates；再补齐上述面试专项，连续 2 套 SQL 模拟面试达到 80 分。到线后即可开始 Python，不必把 W3 后面的数据库管理章节全部学完。
